HTTP status code guide

Quick reference
200 · OK

Request succeeded. Check the body for the expected data.

201 · Created

Server successfully created a resource.

301 / 302 · Redirect

Resource moved or redirected. Inspect the final URL.

400 · Bad Request

Missing or invalid input, such as a required query parameter.

401 · Unauthorized

Authentication is missing or invalid.

403 · Forbidden

Server understood the request but denies access.

404 · Not Found

Route or resource does not exist. Check spelling and method.

405 · Method Not Allowed

Route exists but does not support the selected method.

429 · Too Many Requests

Rate limit reached. Reduce request frequency and follow the API policy.

500 · Internal Server Error

Unexpected server error. Check the application deploy logs.

502 · Bad Gateway

Gateway received an invalid response or could not connect upstream. Check port, process, and provider logs.

503 · Service Unavailable

Service or provider is not ready/configured. Check deployment and environment variables.

504 · Gateway Timeout

Upstream took too long to respond. Check timeout and upstream health.

Browser / CORS error

Browser blocked cross-origin access or connection failed; this is not an HTTP status code.
