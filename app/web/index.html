HTTP status guide
Common responses from this API
200 · OKRequest succeeded. Check the body for results or empty arrays.
400 · Bad RequestRequest value is invalid (for example, page must be positive).
401 · UnauthorizedAPI key is missing or invalid when authentication is enabled.
404 · Not FoundUnknown provider, anime ID, or route.
422 · Validation ErrorQuery/path value has the wrong type or is outside allowed limits.
500 · Server ErrorUnexpected failure in the API. Check the response body and Railway logs.
501 · UnsupportedThe selected metadata provider does not implement that feature, such as AniList episodes.
502/503/504 · UpstreamA provider or proxy failed, is unavailable, or timed out.
